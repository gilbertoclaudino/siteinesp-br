# Site estático do INESP para GitHub Pages

Este diretório contém a versão estática da página institucional do INESP.

## Estrutura

- `index.html`: página inicial.
- `css/style.css`: identidade visual e responsividade.
- `js/main.js`: funcionamento do menu móvel.
- `assets/site.webmanifest`: metadados do site.
- `imagens/favicon.svg`: ícone do navegador.
- `.nojekyll`: impede processamento desnecessário pelo Jekyll.

## Publicação

Envie o conteúdo deste diretório para a raiz do repositório configurado no GitHub Pages. Em **Settings → Pages**, selecione a branch de publicação e a pasta `/(root)`.

## Limitação

Esta versão é inteiramente estática. Ela não inclui o banco D1 nem o armazenamento do formulário de contato presentes na versão completa do site.
